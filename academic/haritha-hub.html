Haritha Hub — HND Final Project

Project Overview

Haritha Hub was developed as an HND final project focused on creating a sustainable e-commerce platform for home gardening.

The platform was designed to support people who want to grow their own food at home, including people living in smaller spaces such as balconies or apartments.

Project Type

HND Final Project E-Commerce Sustainable Living Web Application

Key Features

  • Responsive online shop
  • Add to cart and checkout functionality
  • Secure login and registration
  • Video tutorials for beginner gardeners
  • Product category filtering
  • Price range filtering
  • Garden-space filtering
  • Admin dashboard
  • Product management
  • Tutorial upload functionality

Technologies

React JS MongoDB Atlas

My Contribution

I worked as part of the project team and contributed to the development of Haritha Hub together with the other team members.

The project provided practical experience in working on a team-based software project and developing an application using modern web technologies.

What I Learned

This project helped me gain practical experience in web application development, teamwork and working with technologies such as React JS and MongoDB Atlas.
